# Fit Finds

A curated list of fashion Instagram accounts and shops in one simple place.

**Live site:** https://fit-finds.vercel.app

## Features

- Search by username, note, or category
- Filter chips: Streetwear, Luxury, Sportswear, Local (Dar), International, Shoes
- Sort by name, website, Local (Dar) first, or category
- Profile pictures (via unavatar.io, with letter fallback)
- Open Graph / social preview tags
- Installable as a PWA (Add to Home Screen)
- Simple admin: tap the title **5 times** to add/edit accounts (saved in your browser)

## How to add accounts permanently

1. Open the site and tap **Fit Finds** five times to open Admin
2. Add or edit accounts
3. Click **Export data (copy)**
4. Paste the JSON into `DEFAULT_PROFILES` in `index.html` and commit

## Tech

Static HTML/CSS/JS — no backend required. Deployed on Vercel.
